# AES ENEM Review

## Overview

This repository contains a comprehensive survey and review of **AES (Redação - Portuguese Writing Essay)** within the context of **ENEM** (Exame Nacional do Ensino Médio - Brazilian National High School Exam). The project aims to analyze, document, and provide insights into the writing component of Brazil's most important standardized educational assessment.

## Project Objectives

The primary objectives of this repository are to:

1. **Document AES Requirements** - Maintain detailed documentation of ENEM's essay writing requirements, evaluation criteria, and structural guidelines
2. **Analyze Writing Patterns** - Study and categorize successful essay patterns, writing techniques, and common pitfalls in ENEM submissions
3. **Provide Resources** - Compile learning materials, examples, and references for students preparing for the writing section
4. **Track Evolution** - Monitor changes and updates to AES evaluation criteria across different ENEM editions
5. **Create Reference Materials** - Develop comprehensive guides and checklists for essay preparation and self-assessment
